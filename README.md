# Giorno e Notte

**A menu for every moment.** Giorno e Notte is a restaurant website with fresh, nourishing lunches by day, comforting dinners by night, and a warm atmosphere in between.

## Explore

- **Home** — the restaurant story, team, and a day-to-night New York slideshow.
- **Lunch** — light, fresh dishes for daytime.
- **Dinner** — comforting dishes for the evening.
- **Contact** — restaurant contact details.

## Publish with GitHub Pages

### Create the repository

1. Sign in to GitHub and open `https://github.com/new`.
2. Enter a repository name, such as `giorno-e-notte`.
3. Choose **Public**.
4. Leave **Add a README file**, **Add .gitignore**, and **Choose a license** unchecked because this project already includes those files.
5. Click **Create repository**.

### Upload this website

1. On the new repository page, click **Add file → Upload files**.
2. Open this website folder.
3. Select every project item except operating-system metadata or editor configuration: `.nojekyll`, all HTML files, `README.md`, `css/`, `js/`, `fonts/`, `images/`, and `scss/` if you want to keep the source styles.
4. Drag those items into the GitHub upload area. Do not upload a folder named `pizza-gh-pages`; the contents must appear at the repository root.
5. Confirm that `index.html` is visible beside `README.md` and the `css/`, `js/`, `images/`, and `fonts/` folders.
6. Enter a commit message such as `Publish Giorno e Notte website`.
7. Click **Commit changes**.

### Enable GitHub Pages

1. Open the repository **Settings** tab.
2. Select **Pages** in the left sidebar.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Choose `main` for the branch and `/ (root)` for the folder.
5. Click **Save**.
6. Wait one to three minutes, refresh the Pages settings, and use the URL shown under **Your site is live at**.

The URL will normally be `https://YOUR-GITHUB-USERNAME.github.io/REPOSITORY-NAME/`. GitHub Pages may take a few minutes to publish the first upload. To update the site, repeat the upload or commit your edited files in GitHub.

## Run locally

Open `index.html` in a browser. The menu, styles, scripts, fonts, and images are included in this repository.
